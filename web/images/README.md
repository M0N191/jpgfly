# JPGFLY image assets

This directory contains tracked JPGFLY artwork and branding assets:

| Asset | Role |
|---|---|
| [fly.png](fly.png) | Fly performer image used by the browser. |
| [jpgfly-icon-white.png](jpgfly-icon-white.png) | Site icon and manifest image. |
| [github-banner.jpg](github-banner.jpg), [github-banner.svg](github-banner.svg) | Repository banner variants. |

Additional banner variants are tracked at the repository root and in `assets/`. The repository also includes [web/favicon.png](../favicon.png).
